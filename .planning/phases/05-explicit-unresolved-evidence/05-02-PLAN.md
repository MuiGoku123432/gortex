<objective>
Give the resolver (05-08) a bounded, kind-guarded way to remove `EXTERNAL_UNRESOLVED` finding nodes that are no longer produced, on both store backends, so a retrieved or bound target closes only its own findings (GAP-07) and nothing else is ever deleted by ID.

Purpose: the resolver keeps a desired set of external findings and must evict the undesired ones without touching real source-owned nodes (D-05, D-06). File eviction cannot do it: an external finding is owned by the referencing source file, which did not change.
Output: `FindingNodeBatchEvicter`, the `EvictFindingNodesByIDs` dispatcher, both backend implementations, fence and conformance coverage.
</objective>
