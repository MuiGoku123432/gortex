## Flagged assumptions

- Revision 1 split this plan out of the original resolver plan (05-05 keeps placeholders and edge retargeting). It reads only the `cobolExternalRef` list 05-05 collects, so references are decided once.
- Discretion (edge kinds, CONTEXT): `member_of` (finding to the edge's From node) and `references` (finding to placeholder); no `blocked_by`, because Phase 6 QUERY-09 can count code in-edges (`calls`/`imports`) to placeholders, which edge kind already separates from finding edges (RESEARCH Open Question 5).
- Discretion (external evidence): the digest covers the whitespace-collapsed verb or copy form (`cobol_call` or `cobol_copy_form`), the IDMS kind when present (`cobol_copy_idms_kind`), and the as-written target (`cobol_target_raw` or `cobol_copy_member_raw`), joined with `\x00`; the resolver never reads source and never re-normalizes names (P4 D-18). The as-written spelling is hashed, never stored.
- Discretion (container): the edge's From node (paragraph, program, or copybook file node), not the statement node, matching the edge that makes the reference.
- Pattern 3 maps the artifact type to the family slot for external findings: it is both the `family` argument of `FindingSymbol` and the `finding_expected_family` value; `finding_node_kind` is not set (no parser node exists).
- External findings use `finding_scope=unavailable`, the producer's scope word for evidence outside the document, and `finding_severity=medium` with `finding_severity_rule=gortex-finding-severity/1` (D-12).
- The `#k` assignment is the second inline ordinal loop (the extractor holds the first); a `// note:` names the other occurrence; rule of three is not met.
- The FTS sync for resolver-created findings on incremental tails is 05-11 (Pitfall 4); the cold path repopulates FTS from all store nodes after resolution.
- Pitfall 8 (deleting a repository's last COBOL file): the repository's external findings are evicted with their owning file; 05-09's ledger pass is not gated on COBOL presence, so the closures are still recorded.
- Scale (checker warning, revision 2): the existing external findings are read from the `references` in-edges of the reconciled placeholders (the one in-edge read 05-05's sweep already makes, moved to the start of the function), never by streaming `nodesByKindLang(graph.KindFinding, "cobol")`, which would decode the Meta of every finding in every repository, including per-token parse findings (D-18), on every incremental COBOL edit. The cost is proportional to missing-artifact evidence only.
