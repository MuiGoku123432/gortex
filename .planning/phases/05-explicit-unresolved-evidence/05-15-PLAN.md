<objective>
Give the graph a kind-guarded, set-oriented, by-ID eviction for KindResource nodes on both backends, so the COBOL placeholder sweep (05-16, D-27) can remove placeholders by ID with a kind guard and never through file-path eviction.

Purpose: D-27 requires the sweep to evict placeholders by ID; no generic node removal exists in the store, and file eviction is what let a repository path collide with a placeholder (review WR-05).
Output: one new graph capability with its dispatcher, two backend implementations sharing a private SQLite helper, unit tests, the generation registries, and a storetest conformance case.
</objective>
