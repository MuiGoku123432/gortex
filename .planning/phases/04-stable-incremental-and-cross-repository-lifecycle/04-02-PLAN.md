<objective>
Close the two extractor-side identity gaps the rest of Phase 4 builds on. First, encode every program ID component with `cobolIDSegment` (review IN-03), so a literal PROGRAM-ID containing `/` or `#` can no longer alias a nested path or a `#k` ordinal (ID-03). Second, keep each literal CALL and COPY edge's original placeholder in `cobol_placeholder`, and the normalized `OF`/`IN` library in `cobol_copy_library_key`, so that the resolver can re-decide a bound edge and the indexer can restub it without a second normalization rule (D-18, D-10). Then prove that repeated relationship occurrences keep distinguishable provenance (ID-05).

Purpose: the reconcile pass (04-06) and the CR-01 restub branch (04-08) both depend on `cobol_placeholder`; ID-03 is a forgery-resistance fix.
Output: two small extractor edits and one new unit-test file.
</objective>
