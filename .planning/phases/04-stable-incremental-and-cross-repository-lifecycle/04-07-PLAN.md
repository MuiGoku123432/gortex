## Flagged assumptions

- Config placement follows research A2: per-repository `.gortex.yaml` under `index.cobol` ("workspace config" in this codebase is the per-repository file loaded by `LoadWorkspaceConfig`; `cross_workspace_deps` is the precedent). Every per-repository Indexer already receives `cfg.Index`, and `indexConfigHash` covers it for view generations.
- Library names and default qualifiers must be written as cobol-name-norm/1 keys (upper-case ASCII, unquoted) so that the resolver compares them by exact string equality and carries no second normalization rule (D-18). Delimited (quoted) DB2 schemas cannot be configured as defaults; the validation error says so.
- An unknown repository in `resolve_from` is dropped with a Warn at lookup time because config validation cannot know which repositories are tracked.
