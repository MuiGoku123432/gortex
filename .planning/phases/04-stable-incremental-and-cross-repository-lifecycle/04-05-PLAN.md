<objective>
Make repository ownership a hard, visible invariant (SEC-08). Treat single-repo mode as a workspace of one (D-14): `PrefixDiagnostics.Clean` stops accepting a wholly unowned graph, and the implicit ownership exemptions become one enumerated list shared by the in-memory and SQLite audits. Report it (D-15): `index_health.repo_ownership.status` is `healthy` or `unhealthy` with counts and samples, without blocking queries. Roll it out with migration v22, reusing the existing idempotent purge. Plan 04-13 (wave 4) then routes the embedded `gortex mcp --index` path through `MultiIndexer` so it stops writing unprefixed nodes.

Purpose: SEC-08 requires zero unowned or misprefixed nodes for the acceptance corpus, and Phases 6 and 7 will gate on this status.
Output: strict audit, enumerated exemptions, health status, v22, and tests.
</objective>
