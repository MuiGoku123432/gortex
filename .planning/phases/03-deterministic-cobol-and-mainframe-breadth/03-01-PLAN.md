### Phase contract (every Phase 3 plan follows this table)

**ID grammar** (repo-relative; `applyRepoPrefix` prepends `<repo>/`; every name-derived segment passes through `cobolIDSegment`; names keep source spelling):

| Construct | Kind | `cobol_kind` | ID |
|---|---|---|---|
| Program (P2, unchanged) | `KindFunction` | `program` | `<path>::OUTER/INNER#k` |
| Division | `KindPackage` | `division` (+`cobol_division`) | `<path>::<prog>/@<observation kind>` |
| Data or environment section | `KindPackage` | `section` (+`cobol_section_kind`) | `<path>::<prog>/@<observation kind>` |
| Procedure section | `KindFunction` | `section` (+`cobol_section_kind=procedure`, `cobol_ordinal`) | `<path>::<prog>/@proc/<SECT>` |
| Paragraph | `KindFunction` | `paragraph` (+`cobol_ordinal`) | `<path>::<prog>/@proc/[<SECT>/]<PARA>` |
| Statement | `KindLocal` | `statement` (+`cobol_statement_kind`) | `<container ID>/@<observation kind>` |
| Data item 01/77 | `KindVariable` | `data_item` | `<path>::<prog>/<NAME>` |
| Data item 02-49, 66, 88 | `KindField` | `data_item` | `<parent item ID>/<NAME>`; FILLER and unnamed entries `…/FILLER#k`, k = 1-based among FILLER siblings |
| Copybook-owned data item (D-16) | as above | `data_item` | `<copybook path>::<NAME>/…` |
| Copybook file | `KindFile` | `copybook` | `<path>` |
| DB2 table | `KindTable` | — | `db2::<SCHEMA key or _unqualified>/<TABLE key>` |
| IDMS record, set | `KindResource` (`resource_type=idms_record`, `idms_set`) | — | `idms::_unqualified/record/<key>`, `idms::_unqualified/set/<key>` |
| CICS transaction, map, mapset | `KindResource` (`resource_type=cics_transaction`, `cics_map`, `cics_mapset`) | — | `cics::transaction/<key>`, `cics::map/<MAPSET key or _unqualified>/<key>`, `cics::mapset/<key>` |

`#k` (k >= 2) is appended to the second and later node with the same full ID path regardless of kind, except FILLER, which always carries `#k` starting at 1. Line numbers never enter IDs.

**Edges.** Structural: `defines` from the file node to every symbol node except statements; `member_of` from child to container; no Meta (D-17). Relationship (`calls`, `references`, `imports`, `reads`, `writes`): cloned `docMeta` plus `prov_observation_kind`, `prov_affected`, the occurrence range keys from `cobolStampMeta`, `cobol_statement_symbol` (the statement QualName, added by 03-03, Pitfall 5), Origin `ast_resolved`, Confidence 1.0, ConfidenceLabel `EXTRACTED`, Line = occurrence start row + 1 (0 when the occurrence has no original image). From = the innermost paragraph, else the section, else the owning program node; outside any procedure division, the owning program node; outside any program, the file node.

**Unresolved targets** (`unresolved::` prefix, never repo-prefixed; `<prog>` is the repo-relative program ID `<path>::<program symbol>`; `<key>` is `cobolIDSegment(cobolNameNorm(raw))`):
`unresolved::cobol::program::<key>`, `unresolved::cobol::copybook::<key>`, `unresolved::cobol::copybook::idms/<kind key or _>/<key>`, `unresolved::cobol::dynamic::{program,transaction,map,mapset,sql}::<prog>::<key>`, `unresolved::cobol::label::<prog>::<key>` (qualified `<section key>/<key>`; invalid THRU `<start key>::thru::<end key>`), `unresolved::cobol::data::<owner>::<key>[/<qualifier key>…]` (owner is the program ID, or the copybook path for copybook-owned items, D-16), `unresolved::cobol::idms_scope::_unqualified/<key>`.
