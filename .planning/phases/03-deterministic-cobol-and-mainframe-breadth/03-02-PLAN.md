Close the CR-01 residual that Phase 2 deferred to Phase 3: the always-on BOM strip runs before extraction, so `prov_start_byte`/`prov_end_byte` are relative to the stripped bytes. Correct them inside the existing Phase 2 D-18 indexer hook (`stampSourceRevision`), the only place that knows both the root path and the indexed bytes, and extend that hook so relationship edges also carry the VCS revision stamp every COBOL node has.

Purpose: Phase 3 multiplies byte-bearing nodes and adds byte-bearing edges; PROV-03 exactness must hold for all of them, and the carried-forward provenance contract applies to edges too.
Output: `alignProvByteOffsets`, edge stamping in `stampSourceRevision`, two unit tests, and a real-extractor BOM test.
</objective>
