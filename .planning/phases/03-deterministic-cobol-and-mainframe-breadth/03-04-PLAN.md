<objective>
Make Gortex's resolver honour D-09 and D-11 for COBOL: the existing generic passes bind the first same-file match and lift bare names across repositories, which would be false deterministic resolution. Give COBOL its own owned namespace (`unresolved::cobol::`) with four one-line exclusions, and add one whole-graph pass, `resolveCobolReferences`, that binds literal program calls and copybook references only to exactly one same-repository candidate, stamping `missing` or `ambiguous` (with candidate IDs) otherwise (D-12).

Purpose: the extractor plans (03-07 onward) emit COBOL unresolved targets; without this plan they would be mis-bound or marked terminal by generic passes. This plan works from the contract strings in `03-01-PLAN.md` and seeded graphs, so it runs in parallel with the structure plan.
Output: the exclusions, `internal/resolver/cobol_references.go`, its call site, and tests.
</objective>
